## 🚀 Stack technique

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS 4** + shadcn/ui
- **Supabase** (Auth + Database + RLS)
- **Stripe** (Checkout + Customer Portal + Webhooks)
- **Groq** (IA ultra rapide - Llama 3.3 70B, Gemma, Mixtral)
- **Framer Motion** + Sonner (toasts)
- **Zod** + React Hook Form
